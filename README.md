# Ember & Oak 🍷

![Ember & Oak preview](screenshot/ember-oak-preview.avif)

A modern, responsive restaurant website built from scratch using HTML, CSS, and vanilla JavaScript.

## 🌐 Live Demo

[View Live Website](https://embandoak.netlify.app/)

## 📸 About The Project

Ember & Oak is a fictional restaurant website designed to create a warm, elegant, and modern dining experience online.

The website features a responsive layout, restaurant information, featured dishes, gallery, testimonials, contact information, Google Maps integration, and a responsive footer.

## ✨ Features

- Responsive design for desktop, tablet, and mobile
- Responsive navigation menu
- Hero section with call-to-action buttons
- Featured dishes section
- About section
- Restaurant gallery
- Interactive testimonial carousel
- Previous/next testimonial controls
- Testimonial dot navigation
- Automatic testimonial slideshow
- Touch/swipe testimonial navigation
- Contact section with Google Maps
- Clickable phone and email links
- Responsive footer
- Hover animations and transitions

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Maps Embed
